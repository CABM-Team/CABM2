## 知识库系统 - 每个角色独立

### 概述

知识库系统已改造为每个角色独立的知识库，支持：
- 每个角色拥有独立的知识库文件（`<角色ID>/knowledge.json`）
- 知识库开关独立控制
- 从聊天页面的"更多选项"进入（群聊模式禁用）
- 返回时回到对应的聊天页面
- 自动检测C++插件，未检测到时自动关闭知识库并显示提示

### 文件结构

```
user://characters/<角色ID>/
  ├── <角色ID>.json          # 角色配置
  ├── knowledge.json         # 知识库数据（新增）
  ├── 1.png                  # 立绘
  └── ...

res://characters/<角色ID>/   # 内置角色（只读）
  ├── <角色ID>.json
  ├── knowledge.json         # 可选，会被复制到user://
  └── ...
```

### 知识库数据格式

```json
{
  "enabled": true,           // 知识库开关
  "entries": [               // 知识条目数组
    {
      "id": "uuid",
      "text": "知识内容",
      "embedding": [0.1, 0.2, ...]  // 向量
    }
  ]
}
```

### 使用流程

1. **进入知识库页面**
   - 在聊天页面点击"更多选项" → "📚 知识库"
   - 群聊模式下该按钮禁用
   - 自动加载当前角色的知识库

2. **编辑知识库**
   - 页面标题显示"知识库 - <角色名>"
   - 可以开关知识库功能
   - 批量导入TXT文件（每行一条）
   - 手动添加单条知识
   - 检索测试

3. **返回聊天**
   - 点击"返回"按钮回到聊天页面
   - 知识库自动保存

4. **对话时检索**
   - 发送消息前自动检索相关知识（如果启用）
   - 检索结果作为system消息加入提示词
   - 打印嵌入用时、检索用时等调试信息

### 性能监控

系统会打印以下调试信息：
- `[VectorStore] 加载了 X 条知识库条目，用时 X ms`
- `[KnowledgeBase] 嵌入完成，用时 X ms`
- `[VectorStore] 检索完成，找到 X 条结果，用时 X ms`
- `[ChatController] 知识库检索完成，用时 X ms`

### 插件检测

如果未检测到`CosineCalculator` C++插件：
- 知识库开关自动关闭并禁用
- 显示警告："⚠ 未检测到C++插件，知识库功能已自动关闭"
- 提示用户编译并安装插件

### 导入导出

- 角色导出时会包含`knowledge.json`
- 角色导入时会自动导入知识库
- 兼容旧版本（没有知识库的角色）

### 修改的文件

1. **VectorStore.gd** - 支持每个角色独立的知识库文件
2. **KnowledgeBaseController.gd** - 接收角色ID，显示角色名，添加开关和警告
3. **ChatController.gd** - 加载角色知识库，处理知识库按钮，检索时检查开关
4. **ChatUIController.gd** - 添加knowledge_requested信号，群聊模式禁用按钮
5. **KnowledgeRetriever.gd** - 无需修改（已兼容）
6. **知识库.md** - 更新文档
