# CABM2 功能文档

> 本文档基于 CABM（Python+Flask+HTML 版本）整理，作为 Godot 4.5 重制版的参考规格。

---

## 一、项目概述

CABM（Code Afflatus & Beyond Matter）是一个沉浸式 AI 对话应用，风格类似视觉小说（Galgame）。用户可以与 AI 角色进行深度互动，支持多角色、剧情模式、语音合成、长期记忆等功能。

重制目标：使用 Godot 4.5 重写客户端，保留核心功能，修复架构缺陷，提升可维护性与跨平台能力。

---

## 二、核心功能模块

### 2.1 角色系统【√】

- 每个角色由一个 `.toml` 配置文件定义，包含：
  - `id`：唯一标识符
  - `name` / `name_en`：中英文名称
  - `image`：立绘目录路径
  - `calib`：立绘 Y 轴校准偏移
  - `scale_rate`：立绘缩放比例（百分比）
  - `color`：角色名称显示颜色（十六进制）
  - `description`：角色简介
  - `prompt`：AI 系统提示词
  - `welcome`：进入对话时的欢迎语
  - `moods`：情绪列表（每个情绪对应一张立绘图片）
  - `examples`：对话示例（few-shot）

- 支持内置角色和用户自定义角色
- 角色切换时重新加载立绘和系统提示词
- 立绘目录结构：`images/{CharacterID}/{mood}.png`

### 2.2 对话系统【√】

- 调用 OpenAI 兼容 API（默认 DeepSeek-V3）
- 支持流式输出（Streaming），以句子为单位分段显示
- 暂停标记：`。！？!?...…♪~` 触发分段
- 消息历史管理，可配置最大长度（默认 8 条）
- 系统提示词注入（角色 prompt + 记忆检索结果）
- AI 响应格式：JSON，包含 `content`（正文）、`mood`（情绪）、`notes`（内心独白，可选）

### 2.3 情绪与立绘系统【√】

- AI 每次回复携带情绪标签（如"害羞"、"兴奋"）
- 根据情绪实时切换角色立绘
- 立绘有呼吸动画（上下浮动）
- 多角色模式下，每个角色独立显示立绘

### 2.4 记忆系统（RAG）

- 使用向量数据库（FAISS）存储对话历史
- 每次对话前检索相关记忆，注入系统提示词
- 支持多路召回：
  - 余弦相似度（Embedding API）
  - BM25（可选，关键词匹配）
- 重排序（Reranker API）提升检索精度
- 每个角色独立的记忆数据库，存储于 `data/memory/{CharacterID}/`
- 配置项：`top_k=5`，`timeout=10s`，`min_similarity=0.3`

### 2.5 选项生成系统

- 每轮对话后，AI 自动生成 3 个用户可选的回复选项
- 使用轻量模型（默认 Qwen3-8B）生成
- 用户点击选项直接发送，也可手动输入

### 2.6 剧情模式（Story Mode）

- 创建故事时，AI 生成 40-60 个章节大纲节点
- "导演 AI" 判断当前章节是否推进
- 支持多角色剧情（角色间切换对话）
- 角色切换通过流中的 `<SWITCH_CHARACTER:ID:Name:Mood>` 标记实现
- 故事存档保存于 `data/saves/{StoryID}/story.toml`
- 存档包含：标题、角色列表、当前章节、章节大纲、最后游玩时间

### 2.7 语音合成（TTS）

- 支持两种后端：
  - SiliconFlow API（云端，默认）
  - GPT-SoVITS（本地，推荐有独显用户）
- 每个角色可配置独立的参考音频
- 音频静音裁剪（可配置阈值）
- 流式输出时，句子完成后立即触发 TTS，实现近实时语音

### 2.8 背景系统

- 支持静态背景图片（本地文件）
- 支持 AI 生成背景（调用图像生成 API，默认 Kwai-Kolors）
- 背景图片存储于 `data/backgrounds/`
- 每个角色记录最后使用的背景
- 背景选择器 UI（弹窗）

### 2.9 背景音乐（BGM）

- 支持本地音乐文件播放
- 可上传自定义 BGM
- 音乐资源管理页面

### 2.10 对话历史查看

- 弹窗显示完整对话历史
- 历史记录持久化存储（`.log` 文件，`data/history/`）
- 时间跟踪器记录对话时间

### 2.11 角色知识库

- 每个角色可有独立的背景故事/知识文档（`data/details/{CharacterID}.json`）
- 通过 RAG 在对话时检索注入

### 2.12 配置系统

- 首次启动检测配置，未配置则进入配置向导页面
- 配置项通过 `.env` 文件管理：
  - `CHAT_API_KEY` / `CHAT_API_BASE_URL` / `CHAT_MODEL`
  - `IMAGE_MODEL`
  - `MEMORY_API_BASE_URL` / `MEMORY_API_KEY` / `EMBEDDING_MODEL` / `RERANKER_MODEL`
  - `OPTION_MODEL`
  - TTS 相关配置
- `config.py` 中有详细的模型参数配置

## 三、UI 页面结构

| 页面 | 功能 |
|------|------|
| 主页（index） | 角色展示、进入对话入口 |
| 角色选择（select_character） | 角色列表、历史记录预览 |
| 对话页（chat） | 主对话界面，立绘+对话框+输入框 |
| 剧情列表（story） | 故事存档列表、新建故事 |
| 剧情对话（story_chat） | 剧情模式对话界面 |
| 自定义角色（custom_character） | 创建/编辑角色 |
| 设置（settings） | 用户偏好设置 |
| 资源管理（resource_management） | BGM/背景图上传管理 |
| 配置向导（config） | 首次启动 API 配置 |

## 四、数据目录结构

```
data/
├── backgrounds/        # 背景图片
├── details/            # 角色知识库 JSON
├── history/            # 对话历史日志
├── images/             # 角色立绘（按角色ID分目录）
├── memory/             # 向量记忆数据库（按角色ID分目录）
│   └── {CharID}/
│       ├── {CharID}_memory.db
│       ├── {CharID}_faiss.index
│       ├── {CharID}_metadata.json
│       └── {CharID}_texts.pkl
└── saves/              # 剧情存档
    └── {StoryID}/
        └── story.toml
```

## 五、API 接口依赖

| 功能 | API 类型 | 默认模型 |
|------|---------|---------|
| 对话 | OpenAI 兼容 | DeepSeek-V3 |
| 选项生成 | OpenAI 兼容 | Qwen3-8B |
| 图像生成 | 图像 API | Kwai-Kolors |
| 文本嵌入 | Embedding API | BAAI/bge-large-zh |
| 重排序 | Reranker API | BAAI/bge-reranker-large |
| 语音合成 | TTS API | SiliconFlow / GPT-SoVITS |

## 六、已知问题（来自原项目）

- 进入聊天页面时背景变暗（视觉 bug）
- 查看历史时显示完整对话而非截断
- 加载角色时文件无法加载（浏览器安全限制）
- 语音输入功能几乎不可用
- 全局服务单例导致多用户/多窗口状态混乱
